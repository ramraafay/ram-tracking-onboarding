## Dependencies
- nix
- direnv (optional)

Or if you don't want to use nix…

### Backend Dependencies
- jdk21
- maven3

### Frontend Dependencies
- nodejs_22
- pnpm

## Setup
Activate development environment by running…

```sh
nix-shell
```

Or if you're using a shell hooked with direnv…

```sh
echo use nix > .envrc
```
